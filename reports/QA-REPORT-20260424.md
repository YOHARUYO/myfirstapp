## 3. 주요 발견 및 결정 사항

### 🔴 E1: 재편집 전체 실패 — 근본 원인 발견 + 수정 확인

**현상:** 재편집 진입 후 블록 분할/병합/텍스트/중요도/AI 태깅/요약 전부 404
Console: `POST /api/meetings/undefined/blocks/...`

**근본 원인:**
1. HistoryDetail이 `session_id: meeting.meeting_id`로 fake Session 생성 → store 저장 ✅
2. Editing mount 시 `api.get('/meetings/mtg_xxx')` → 서버가 Meeting 객체 반환 (`meeting_id`만 있고 `session_id` 없음)
3. `setSession(res.data)` → store가 `session_id` 없는 데이터로 덮어씌워짐
4. 이후 모든 API 호출에서 `session.session_id` → `undefined`

**수정:** `ensureSessionId()` 유틸 함수로 Editing.tsx 5곳 + Summary.tsx 1곳에 매핑 적용 → ✅ 확인 완료
