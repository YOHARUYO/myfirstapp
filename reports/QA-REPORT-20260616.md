## 3. 발견 이슈 및 분석

### 3-1. 본 사건 진단 체인 (확정)

```
Anthropic API: claude-sonnet-4-20250514 → 404 not_found_error
   ↓
services/llm/claude.py:ClaudeProvider.summarize() — anthropic.APIStatusError
   ↓
services/claude_service.py:_safe_call — HTTPException(502, "LLM API 오류 (404)...")
   ↓
Vite proxy → cloudflared → "The origin web server returned an invalid or incomplete response"
```

블록 병합 실패 토스트는 별건이 아니라 **자동 재태깅 경로가 동일 모델 호출 → 502 → 토스트** 사슬. 모델 ID 교체 후 같은 세션에서 블록 병합 정상 동작 확인됨(PM 보고).

부수 발견 — `/api/sessions/mtg_20260616_9cfbfb4e/...` 404는 본 장애와 무관. frontend가 meeting ID(`mtg_`)를 sessions 경로로 호출한 일시적 라우팅 실수 (Phase 1B에서 `Editing.tsx:saveMetadata` editMode 분기 fix가 들어간 영역과 유사 패턴이지만 별도 경로 — 본 사건과 분리).
